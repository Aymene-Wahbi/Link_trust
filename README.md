> **LinkTrust** is a lightweight, real-time URL analysis engine designed to evaluate web link security, detect phishing attempts, and highlight domain anomalies before you click.

---

## 🎯 The Core Problem: Why HTTPS Isn't Enough

A common security myth is that a **padlock icon in the address bar (HTTPS)** guarantees a website is safe. In reality, **over 80% of modern phishing websites operate over valid HTTPS connections** (Source: APWG).

* **HTTPS = Encrypted Transit:** Ensures that data exchanged between your browser and the server cannot be intercepted by third parties.
* **HTTPS ≠ Site Legitimacy:** Does not verify whether the server owner is a legitimate business or a malicious actor.

**LinkTrust** bridges this gap by evaluating the underlying domain characteristics, visual spoofing patterns, and structural indicators beyond basic SSL encryption.

---

## ✨ Key Features

* 📊 **Dynamic Risk Scoring:** Instant visual safety gauge (0–100 scale) categorized into Clear, Warning, or High Risk status.
* 🔍 **Multi-Factor Heuristic Engine:**
  * **Typosquatting & Impersonation:** Identifies character substitutions used to mimic popular brands (e.g., `paypa1.com`, `g00gle.com`).
  * **Protocol Breakdown:** Differentiates between raw transport security (HTTP/HTTPS) and domain intent.
  * **Redirection & Shortener Detection:** Flag masked destinations generated by URL shorteners (e.g., `bit.ly`, `tinyurl`).
* 🌐 **Internationalization (5 Languages):** Built-in support for English 🇬🇧, French 🇫🇷, Spanish 🇪🇸, German 🇩🇪, and Arabic 🇸🇦 with automatic **RTL (Right-to-Left)** layout adjustment.
* 🌓 **Adaptive UI Themes:** Seamless switching between *Ultra Deep Dark* mode and *Clean SaaS Light* mode.
* 📚 **Security Awareness Module:** Built-in educational guide explaining transport security vs. domain legitimacy.
